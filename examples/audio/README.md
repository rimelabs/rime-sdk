# Speech fixture

`france.wav` contains: "The capital of France is Paris."

This synthetic speech was generated with Prism during SDK validation and
converted to mono 16 kHz signed little-endian PCM16 WAV. It contains no customer
audio. It is included under this repository's MIT license for examples and tests.

Prism can acknowledge the statement; the exact reply can vary. Supply your own
spoken question with the recorded example's `--input` option.
